Request Body schema: application/json
required
schema_version
required
string (SchemaVersion)
Value: "1"

Версия конверта. Несовпадение — 400, задача в failed без ретраев.

request_id
required
string <uuid>

request_id из запроса задачи (= ai_jobs.id или id повторной отправки после failed)

attempt_id
string <uuid>

есть у evaluate_*; отсутствует у generate/tts

type
required
string (JobType)
Enum: "evaluate_grammar" "evaluate_semantic" "evaluate_dialogue" "generate_scenario" "tts"

evaluate_dialogue — оценка разговора оператора с заявителем (голосовой режим): протокол опроса, речевые метрики, тон. Добавлен v1.1.

status
required
string
Enum: "ok" "failed"
object (AiJobError)
required
object (Engine)

Воспроизводимость оценки (ТЗ: QA модели). Пишется в evaluations.engine / scenarios.generation_meta как есть.

object (GrammarResult)
object (SemanticResult)
object (DialogueResult)

Результат оценки разговора (слой dialogue). score — сырой 0..100, вес слоя и итог считает go-core.

object (ScenarioResult)
object (TtsResult)
