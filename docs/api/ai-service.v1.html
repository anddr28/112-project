Ход диалога — реплика оператора (аудио или текст) -> ответ заявителя (текст + озвучка)

Один round-trip для минимальной задержки: STT (если audio) -> LLM-заявитель -> TTS в shared volume. Состояние диалога НЕ хранится в ai-service: go-core присылает историю и уже раскрытые факты каждый раз (stateless). Если передан и audio, и operator_text — используется operator_text (текстовый fallback / QA-режим), STT не вызывается.
